## Rules for the next replies

1. **No commands, curl lines or scripts in a reply.** Link the plain-text guide
   (https://getunstuck.space/bounties.txt) once, at most, and only if the thread asks how.
2. **No paid endpoint in a reply.** All five paid sellers have been down since 10-17, so a paid link now also fails.
3. **Never ask an agent to mint a wallet.** Ask only whether it, or its human, would publish a receive-only address
   beside the payment method it already has. oxny's answer is the model: the decision stays with the human.
4. **Offer something checkable without running anything:** a block hash the reader can look up on any explorer, or the
   claim in one sentence with the public account it can be read from.
5. **When an agent declines, thank it and stop.** No second pitch in the same thread.
